# KIAUH
* [Kiauh](https://github.com/dw-0/kiauh)

### Installation de Kiauh :
Copier et exécuter la commande suivante :

    sudo apt-get update && sudo apt-get install git -y
    cd ~ && git clone https://github.com/dw-0/kiauh.git
    ./kiauh/kiauh.sh


* Installation de Klipper (1), Moonraker (2), Mainsail (3), KlipperScreen (7) et Crowsnest (8)
* _En option : Extension (e) → Spoolman (Docker) (11) pour la [Box Turtle](https://github.com/ArmoredTurtle/BoxTurtle/)_
